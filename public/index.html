إعدادات الربط والمنصات (SaaS Workspace)

📘 ربط فيسبوك وانستجرام (Meta Graph API)

إلزامي للنشر

أدخل مفتاح الوصول (System User Token أو User Token) التابع لحساب مطوري Meta الخاص بك:

📖 كيف أحصل على رمز Meta System User Token الدائم لصفحاتي؟ (اضغط للشرح) ▼
  1. توجه إلى إعدادات أعمال Meta (Business Settings).
  2. من القائمة الجانبية، اضغط على المستخدمون (Users) ثم اختر المستخدمون الأساسيون (System Users).
  3. اضغط على زر إضافة (Add)، اكتب اسماً له (مثلاً: SocialFlow) واختر الدور مسؤول (Admin) ثم اضغط إنشاء.
  4. اضغط على زر تعيين أصول (Assign Assets):
    • اختر الصفحات (Pages)، حدد صفحاتك وفعّل خيار التحكم الكامل (Full Control).
    • اختر حسابات Instagram وحدد حسابك وفعّل التحكم الكامل (Full Control)، ثم احفظ التغييرات.
  5. اضغط على زر إنشاء رمز جديد (Generate New Token):
    • اختر تطبيقك (App).
    • في صلاحية الرمز (Token Expiration) اختر: Never (دائم لا ينتهي أبداً).
    • حدد الصلاحيات التالية:
      pages_show_list pages_read_engagement pages_manage_posts instagram_basic instagram_content_publish
  6. اضغط Generate Token، انسخ الرمز والصقه في خانة الرمز أعلاه، ثم اضغط 🔍 جلب وفحص الصفحات!

☁️ التخزين السحابي للوسائط (Cloudinary Storage)

مطلوب لرفع الصور والفيديوهات

⚠️ لحماية خصوصية واستقلالية كل حساب، يتطلب رفع الوسائط إدخال بيانات حساب Cloudinary السحابي المجاني الخاص بك:

📖 كيف أحصل على بيانات Cloudinary المجانية الخاصة بي؟ (اضغط للشرح) ▼
  1. توجه إلى موقع Cloudinary.com وسجل حساباً مجانياً (Free Forever).
  2. بعد تسجيل الدخول، ستفتح لك لوحة التحكم الرئيسية (Dashboard).
  3. ستجد في أعلى الصفحة صندوقاً بعنوان Product Environment Credentials يحتوي على بياناتك الثلاثة:
    • Cloud Name
    • API Key
    • API Secret (اضغط على أيقونة العين لإظهاره أو نسخه)
  4. انسخ كل قيمة وضعها في الحقل المخصص لها بالأعلى، ثم اضغط ⚡ اختبار اتصال Cloudinary لتتأكد من نجاح الاتصال!

📡 ربط الويبهوك وتطبيق Meta (Webhooks & App Setup)

إشعارات وتزامن

استخدم هذه الروابط في صفحة إعدادات الـ Webhooks داخل تطبيق Meta الخاص بك لاستقبال الأحداث فورياً:

📖 دليل إعداد تطبيق Meta والويبهوك خطوة بخطوة (اضغط للتفاصيل) ▼
  1. إنشاء التطبيق: توجه إلى Meta for Developers، اضغط Create App واختر نوع التطبيق Business (أو Other > Business).
  2. إضافة منتج Webhooks: من القائمة الجانبية للتطبيق، اضغط على Add Product واختر Webhooks.
  3. الاشتراك في كائن Page و Instagram: في قائمة Webhooks اختر Page ثم اضغط Subscribe to this object، والصق Callback URL و Verify Token المعروضين بالأعلى واضغط Verify and Save.
  4. تفعيل الحقول: فعّل اشتراك الحقول التالية: feed, messages, comments.
  5. توليد Access Token: من أدوات المطورين Graph API Explorer أو System Users، أنشئ رمزاً بصلاحيات:
    pages_manage_posts pages_read_engagement instagram_basic instagram_content_publish
    ثم الصق الرمز في حقل (قسم 1) بالأعلى واضغط جلب وفحص الصفحات.

كيفية الحصول على مفتاح Groq API مجاناً

خطوات بسيطة وسريعة جداً (مجاني 100% وبدون بطاقة دفع)

💡 مفتاحك خاص بك وحدك: لكل عميل مفتاحه المستقل لضمان خصوصية بياناتك وعدم مشاركة حصة الاستهلاك مع أي صفحة أخرى.
  1. افتح صفحة مفاتيح Groq:
    اضغط على الرابط التالي لفتح لوحة تحكم Groq في نافذة جديدة:
    🔗 الانتقال لموقع Groq Console (console.groq.com/keys) ↗
  2. تسجيل الدخول:
    سجّل الدخول بحساب Google بنقرة واحدة (أو بريدك الإلكتروني). لا يتطلب أي بطاقة بنكية أو فيزا إطلاقاً.
  3. إنشاء المفتاح:
    اضغط على زر Create API Key باللون البرتقالي أو الأخضر.
  4. تسمية المفتاح:
    اكتب أي اسم تريده (مثلاً: SocialBot أو اسم نشاطك) ثم اضغط Submit.
  5. نسخ المفتاح:
    سيظهر لك المفتاح الذي يبدأ بـ gsk_.... اضغط على زر Copy لنسخه فوراً.
  6. الصق المفتاح هنا:
    ارجع لهذه الخانة، الصق المفتاح، واضغط على تحقق ⚡ ثم حفظ.
